# CRAFT GUIDE

Minecraft Java版の個人用攻略ガイド。Windows（Tauri 2 / WebView2）とWebで画面・主要ロジックを共有します。

- Web: https://aresto1126.github.io/craft-guide/
- Source: https://github.com/Aresto1126/craft-guide
- Windows: Releasesの `Craft Guide_0.1.0_x64-setup.exe`（生成・公開状況はリリースページを確認）

## 使い方
1. 「プレイ環境を追加」から、実際にMinecraftを起動するインスタンスのフォルダを選択します。
2. 表示名を決めて登録します。「設定 → インスタンス管理」で編集・再解析・パス変更・登録解除ができます。
3. アイテム名・ID・MOD名で検索し、レシピを選び、必要な個数を計算します。
4. 「カスタム指示」で共通・環境別の好みを保存します。進行状況・設備は環境編集から登録できます。
5. 調べた内容や計算結果を攻略ノートに保存します。

最初の「バニラ参考図鑑」は17アイテム・12レシピの小さな例です。登録したゲーム環境のデータではありません。

## AI・料金・送信
検索・素材計算・ノート・環境解析はAIを使わずローカルで処理します。有料API、有料サーバー、追加クレジット購入への切替はありません。

WindowsのAI相談は導入済みの公式Codex CLIを使用します。利用者自身でChatGPTログインを済ませ、「設定 → AI連携」で確認してください。アプリにログイン機能は追加していません。APIキー認証は拒否します。CLIのAPIキー環境変数とユーザー設定を引き継がず、読み取り専用・一時作業フォルダで実行します。

AI送信前に、開閉欄で質問・指示・関連資料・直近の会話を確認できます。送信同意にチェックし「AIに送信」を押した場合だけ送信します。フォルダパスとMODファイル自体は送信しません。サブスクの利用枠を消費し、上限では回復を待ちます。AIはオンライン機能です。

Web版からCLIは起動できません。「質問をコピー」でChatGPTに貼り付けて相談してください。ChatGPT側のカスタム指示がアプリへ自動継承されることはありません。

## 対応範囲と制約
- JAR/ZIP、データパックのJSON、翻訳、タグ、MODパックメタデータを静的解析します。ゲームファイルは変更しません。
- 対応レシピ：通常の定形・不定形クラフト、製錬・溶鉱・燻製・焚き火、石切りの対応JSON形式。
- 複数レシピ・材料タグは選択できます。素材計算は生成数・端数・中間素材・循環を考慮します。
- 燃料、設置設備、確率出力、副産物は自動最適化の対象外です。
- KubeJS/CraftTweaker等のコードは実行しません。設定ファイルによる挙動、条件付きレシピ、機械独自形式、実行時の登録、有効データパック順序、サーバー独自変更は未確認です。
- 内蔵参考データと静的解析データを明示し、全MOD・全バージョン対応を主張しません。専用連携MODは未実装です。
- ランチャーのルートを選んでも、別ディレクトリの共有バニラJAR等は自動探索しません。必要なら該当データを含むフォルダを明示的に選びます。
- 通常のスキャンは48MB/30000抽出ファイルを上限とし、1アーカイブ128MB、1エントリー2MBなどの制限があります。大きなMOD等は警告付きで省略される場合があります。

## 保存・バックアップ
Windows: `%APPDATA%\jp.craftguide.desktop\state.json`（OS設定により実パスは異なる場合があります）。前回データは `state.bak`。

Web: このサイトのlocalStorage。ブラウザの容量制限があるため、大きな環境で保存に失敗した場合はWindows版を使用してください。ブラウザのデータ削除で消えるので、JSONバックアップを推奨します。

「設定 → インスタンス管理 → バックアップ」でJSONを書出し・読込みできます。保存形式はversion 1。破損データは自動上書きせず、前回バックアップまたは外部JSONから明示的に復旧できます。復旧時の破損原本も保持します。バックアップにはパス・会話・ノートが含まれるので公開しないでください。

## 見た目
右上でライト／ダーク切替。ウィンドウ内の平原／洞窟を半透明パネル越しに表示します。設定から不透明度、文字サイズ、背景表示を変更できます。背景とアイコンはこのプロジェクトのオリジナルSVGです。ゲーム公式素材を同梱していません。Mojang/Microsoftの公式アプリではありません。

## 通信・インストール
Windowsの通常機能はインストール後オフラインで使えます。Web版は初回アクセスでファイルを取得し、Service Workerの準備後は同じURLの再読み込みとローカル機能をオフラインで使えます。ブラウザがキャッシュを削除した場合は再取得が必要です。

WindowsインストーラーはWebView2未導入時にMicrosoftのブートストラッパーを取得するため、インストール時に通信が必要になる場合があります。コード署名は行っていません。

## 開発・検証
Node 24、Rust stable、Windows C++ Build Tools、WebView2が必要です。初回の依存ダウンロードにはネット接続が必要です。React等は使用していません。fflateはWeb版でJAR/ZIPを読むため、Rustのzip/rfdはJARとフォルダ選択のために使用します。

```sh
npm ci
npm test
npx playwright install chromium
npm run test:ui
npm run build
node scripts/verify-production.mjs
cargo test --manifest-path src-tauri/Cargo.toml --locked
npm run tauri -- build --debug --no-bundle
node scripts/verify-native.mjs
npm run build:windows
```

ネイティブ検証はデバッグ版専用の一時保存先を使い、既存利用者データを変更しません。AI推論は通常の検証では行いません。明示的に接続試験を行う場合だけ `CRAFTGUIDE_VERIFY_AI=1` を設定します（サブスク利用枠を消費）。

GitHub ActionsはNode・Playwright検証、Windowsテストとインストーラー生成、Web版ビルドとPages公開を実行します。Pages設定はGitHub Actionsを選択してください。公開されたWeb版とWindows版は独立した成果物です。
