# 開発・AIプロンプト

本プロジェクトでは [AGENTS.md](../AGENTS.md) と [設計仕様](superpowers/specs/2026-10-28-craft-guide-design.md) を全開発工程の共通指示として適用する。全Phaseの承認は利用者から取得済み。

## 開発共通
Tauri 2 / Vite / Rust / ES ModulesでWindows・Webを実装する。UI、ドメイン、データ検証、保存アダプターを分離し、追加課金なし・無断送信なし・ゲームファイル読取り専用・破損保護を優先する。途中で動作を推測で完了扱いしない。必須技術変更は理由と代案を先に示す。

## UI
ライト平原、ダーク洞窟。ウィンドウ内の風景を半透明パネル越しに表示。外部Windows画面には一切描画しない。本文は読みやすい日本語、アイコン・装飾はピクセル調。キーボード操作・文字拡大・不透明表示。左に環境・ナビ、中央に図鑑と設定、右に相談。

## インスタンス・解析
選択フォルダのMOD・データパック・メタデータを静的解析する。JAR内のコードやKubeJSを実行しない。サイズ・件数上限を設け、未知の形式とスクリプト変更を未確認と表示する。環境追加・編集・登録解除・再解析・パス変更、環境別会話・ノート・指示。

## 保存
WindowsはアプリデータJSON、WebはlocalStorage。形式バージョン・移行・バックアップ・参照検証。保存失敗時はメモリ側も確定せず、既存データを保護する。破損データは明示的な復旧操作まで保持する。

## AI相談
実際の基本プロンプトは `src/domain/prompt.js` の `buildPrompt` に集約。共通・環境別・今回の指示を合成する。必要なレシピと直近の会話だけを渡す。送信内容を確認でき、明示同意後に送信。通常APIは使わず、既存ChatGPT認証のCodex CLIを確認する。外部ツールを使わず資料から説明するよう指示し、専用の空の作業フォルダ、読み取り専用サンドボックスを使用。APIキー認証は拒否。利用枠超過時は回復待ち。Web版にはコピー操作を用意。

## 検証・公開
Node/Rust/Playwright、Windows起動とネイティブ保存・再読込み、Web本番サブパス・オフライン、保存破損・不正入力・環境分離を検証。NSIS生成とPages公開は独立工程。実URL未確認なら公開完了としない。
