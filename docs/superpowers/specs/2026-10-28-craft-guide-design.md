# CRAFT GUIDE 設計・実行指示

利用者による仕様・全Phaseの承認済み。新規プロジェクト C:\CodexApp\CraftGuide に実装する。

## 目的・必須条件
個人用Minecraft Java版ガイド。バニラ・MODパック・自作構成をインスタンス別に管理し、検索、レシピ、素材計算、ノート、カスタム指示付き相談を提供する。
Tauri 2 / WebView2 / Rust / Vite / ES Modules。Reactは採用しない。共通画面・ドメイン・検証・保存アダプターを分離。
WindowsはアプリデータJSON、WebはlocalStorage。形式バージョン、移行、検証、JSONバックアップ、破損時保護、保存失敗の日本語表示を必須とする。
有料API・有料サーバー・追加購入なし。利用者データは明示的な送信操作まで外部に送らない。通常のローカル機能はオフライン。ログイン・クラウド同期・自動更新をアプリに追加しない。
ピクセル装飾、通常の日本語フォント、キーボード操作と文字拡大。ライトは平原、ダークは洞窟。風景はウィンドウ内のみ、半透明パネル越しに表示する。透明度調整と不透明表示に対応。

## 構成案
1. ローカルアプリ＋ChatGPT認証済みCodex公式CLIによる読み取り専用の明示的な相談：第一候補。サブスク枠を消費。通常APIは使わない。
2. 整形した質問をコピーしてChatGPTで使う：Web版と連携不可時の代替。手動操作が増える。
3. ローカルAI：ゲーム負荷・依存を増やすため初期版では採用しない。
実装上の判断：既存のChatGPT認証を確認するだけとし、アプリ独自ログイン・認証情報読み取り・自動送信はしない。CLI未導入/未認証は具体的に表示する。

## データ取得・制約
ユーザーが選んだインスタンスのみ読む。JAR/ZIPのJSON・MODメタデータ・lang・tagsを静的抽出。スクリプトは実行せず存在を警告。レシピ優先順位やワールドの有効パック順序を確定できない場合は未確認とする。
共有JSで対応バニラ形式を正規化、未知の機械形式は未対応として記録。内蔵の小さなバニラ参考カタログは環境確認済みと区別する。全MOD/全バージョン完全対応は非目標。
専用連携MODは将来拡張とし、今回自動導入しない。
Webはブラウザの明示的なフォルダ選択で読取り、ローカルパスの自動アクセス不可。ブラウザからネイティブCodexを呼ばない。

## 配布・検証
Node標準テスト、Playwright、本番サブパス、Rustテスト、ネイティブ起動・保存を検証。
Windows NSISインストーラーとWeb用成果物を独立生成。GitHub Actionsで検証・Pagesデプロイ・Windowsビルド。公開はCLI認証後、公開URLで確認してから報告する。
GitHub認証や環境制約は未完了として報告し、ビルド成功・実装・検証を区別する。
