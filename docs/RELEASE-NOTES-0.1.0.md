# CRAFT GUIDE 0.1.0

Minecraft Java版の個人用Windows/Webガイドです。

## 主な機能
- インスタンス追加・編集・再解析・パス変更、環境別のノート・会話・指示
- アイテム検索、対応JSONレシピ表示、中間素材を含む素材計算
- ライトの平原／ダークの洞窟、半透明パネル、文字サイズ・不透明度設定
- 共通・環境別・今回のカスタム指示
- 明示同意による既存ChatGPT認証のCodex CLI相談、Web版の質問コピー
- JSONバックアップ、破損データ保護と明示復旧

## ローカル検証
Node 10件、Rust 3件、Playwright 6件が通過。
実際のWebView2起動、Rust保存・再読込み、ネイティブ解析、ChatGPT認証を確認。
個人データを含まない短い接続試験でAI応答を確認。
本番サブパス、風景アセット、オフライン再読込み・素材計算を確認。

## 制約
静的解析版です。KubeJS等の変更・実行時登録・機械独自レシピ・サーバー独自設定などは未確認。全MOD・全バージョン対応ではありません。
WindowsのAI相談には公式Codex CLIと利用者のChatGPT認証が必要です。サブスク利用枠を消費します。有料API・追加購入は行いません。
Web版はAI質問をコピーしてChatGPTで使用します。初回アクセスには通信が必要です。
Windowsインストーラーは未署名です。WebView2未導入時はインストール中に通信が必要になる場合があります。

詳細はリポジトリのREADMEを参照してください。
